What each request means
Chess
fen, optional legal UCI moves, and depth. Native FEN syntax acceptance does not certify legal history, king counts, or clocks. Counts come from the native move tree.
English draughts
paths are native row-major square indices 0..63 from the opening, and depth requests perft. This is not conventional 1..32 notation.
Backgammon
player, dice, and optional turns with player/dice/native selection index. Successors are distinct resulting boards, not exposed checker paths or best moves. Selection order belongs to this build.
Go / Baduk
size, explicit-color placements with 0-based row/column, and query player. Native play accepts explicit colors without enforcing alternating turns. Simple ko and native area scoring are not superko, komi, pass rules, or adjudication.
Browser admission: request 256 KiB, FEN 4 KiB, 128 sequence entries (16 backgammon selections), odd Go size 1..19, dice 1..6, perft depth 0..3 and 100,000 visited preflight nodes, report 2 MiB, WASM memory 64 MiB. Read/startup/computation deadlines are 5/12/10 seconds. Admission preflight bounds work; native perft supplies the reported count. Native CLI limits remain separate.
