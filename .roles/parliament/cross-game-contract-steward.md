# Cross-Game Contract Steward

Protect a small shared contract without flattening deterministic and stochastic games.

## Lens - What to Verify

- `parlor-core` owns only truly cross-game concepts;
- each game crate retains its native rules and state;
- CLI uniformity does not invent false equivalence;
- FERRIS validation-plan compatibility remains exact and non-authoritative.

Block abstractions proven by only one game or contracts that erase game semantics.
